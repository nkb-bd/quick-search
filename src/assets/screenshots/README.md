# Quick Search Screenshots Guide

## Required Screenshots

### 1. Main Popup Interface (1280x800 px)
Show the popup with:
- Search bar
- Auto-suggestions list
- Current search engine indicator
- Theme toggle button

### 2. Theme Switching (1280x800 px)
Show:
- Light theme interface
- Dark theme interface
- Theme toggle button

### 3. Search Engine Selection (1280x800 px)
Show:
- Search engine selector dropdown
- Available search engines (Google, Bing, DuckDuckGo, Yahoo)
- Current selection indicator

### 4. Settings Page (1280x800 px)
Show:
- Keyboard shortcut configuration
- Privacy controls
- Clear history button
- Theme settings

## Promotional Images

### Small Tile (440x280 px)
- Clean, minimal design
- Extension icon
- Brief feature highlight
- Light/dark theme indicator

### Large Tile (920x680 px)
- Hero image showing main interface
- Key features highlighted
- Visual hierarchy showing search flow
- Theme support demonstration

## Naming Conventions

- Screenshots: `screenshot-<description>.png` (e.g., `screenshot-main-interface.png`)
- Promotional images: `promo-<size>.png` (e.g., `promo-small.png`, `promo-large.png`)

## Tips for Creating Screenshots

1. Use clean, uncluttered backgrounds
2. Show the extension in action with sample data
3. Highlight key UI elements with subtle shadows or highlights
4. Maintain consistent lighting and perspective
5. Include the extension icon in the browser toolbar
