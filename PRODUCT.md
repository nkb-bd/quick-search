# Product

## Register

product

## Users

Quick Search serves keyboard-first Chrome and Chromium users who move repeatedly between open tabs, browsing history, bookmarks, and web search. They use it in the middle of another task and expect to find, open, review, and close results without breaking flow or reaching for the mouse.

## Product Purpose

Quick Search provides one dependable shortcut for searching local browser sources and the web from any Chrome page. Success means a new user can invoke it immediately, understand where it opened, find the right destination quickly, and dismiss it with the same shortcut or the keyboard. The side panel is the default experience because it keeps the current page visible while results are reviewed.

## Brand Personality

Fast, calm, and precise. The interface should feel trustworthy and self-explanatory, with the quiet confidence and interaction discipline associated with tools such as Raycast and Linear.

## Anti-references

Do not make Quick Search look like a decorative SaaS dashboard, a marketing page, or a collection of nested cards. Avoid novelty controls, ornamental gradients, glassmorphism, excessive motion, and visual decoration that competes with search results.

## Design Principles

1. Keep the current task visible: prefer surfaces that let users search and compare without losing page context.
2. Make the keyboard path complete: every primary action, state, and dismissal must work without a pointer.
3. Earn attention through hierarchy: emphasize the query and selected result; keep secondary settings and guidance quiet.
4. Use familiar controls consistently: standard fields, radios, buttons, focus states, and labels should behave the same on every screen.
5. Teach in place: first-run and empty states should reveal the smallest useful next action rather than presenting a manual.

## Accessibility & Inclusion

Meet WCAG 2.2 AA for contrast, focus visibility, labeling, and keyboard operation. Do not rely on color alone to communicate state. Respect reduced-motion preferences, support browser zoom and narrow side-panel widths, and keep touch targets usable without making the keyboard-oriented interface visually oversized.
